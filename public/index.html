Fast downloads.
In your terminal.

Download large files with up to 32 parallel connections. Available for Linux, macOS, and Windows.

Get Surge Read the docs

Track every download

See your queue, transfer speeds, and file progress.

Watch before it finishes.

Sequential mode downloads from the beginning so you can preview supported videos or audio while the rest arrives.

Pick up where you paused.

Pause a transfer and resume from the progress already saved.

Replace an expired link.

Give a paused or failed download a fresh link for the same file, then reconnect.

Download from multiple mirrors.

Fetch different parts of the same file from multiple sources. Surge can switch sources if a connection drops.

One file.
Up to 32 connections.

Each connection requests a different byte range at the same time. Surge writes each range at its offset in the same file.
